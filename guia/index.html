O que é

Um plugin (main-design) para o Claude Code

Instala como skill e gera páginas HTML/CSS/JS scroll-driven a partir de uma entrevista com você, obedecendo um padrão de craft fixo — não um template que só troca de cor.

🎞️ Scroll é a timeline

Vídeo scruba quadro a quadro sob a roda do mouse, seções fixam (pin) enquanto o argumento avança, rails deslizam de lado, headlines se montam linha a linha.

🧬 Oito gramáticas, uma por build

Filmic one-shot, editorial em capítulos, superfície viva, mundo contínuo, poster tipográfico, galeria, split stage, cutlist rítmico — cada uma proíbe o que as outras exigem.

🔍 Verifica o próprio trabalho

Um browser headless percorre a página em cada posição de scroll e reporta scroll morto, contraste real, cues que nunca abrem e clipes travados num "poster" congelado.

Como funciona

Da entrevista ao contact sheet

Cada build passa pelo mesmo procedimento antes de virar página final.

Entrevista→ Gramática + fingerprint gate→ Feeling curve + pico→ Build (engine fixo)→ Verificação headless→ Contact sheet

🚧 Fingerprint gate

Um build novo tem que diferir de todo build anterior em pelo menos 4 de 6 dimensões: gramática, nav, hero, forma dos atos, fechamento, signature move. Falhou o gate? Muda o plano, não o registro.

📈 Feeling curve

Uma linha por ato — a emoção e o que na tela causa ela. Dois atos adjacentes com a mesma emoção significa que um é enchimento. Um pico só, com o orçamento de asset e o silêncio antes dele.

Pré-requisitos

O que precisa estar instalado

Rode doctor antes de qualquer coisa — ele acha os três problemas de setup que, sem ele, aparecem depois como erros enganosos.

Node 18+

Necessário para todo script do plugin.

ffmpeg completo

Precisa de um build cheio (com scale), não um stripped de ~50 filtros. SCROLLCRAFT_FFMPEG sobrescreve a busca.

# checagem automática
node scripts/doctor.mjs

playwright-core + Chrome

Usado na passada de verificação. Instala na pasta do build.

# na pasta do build
npm i playwright-core
Guia de uso · passo a passo

Instalar, ativar, construir

Comandos reais, na ordem em que você realmente roda.

1

Adicione o marketplace

Dentro do Claude Code.

/plugin marketplace add inematds/scroll-craft
2

Instale o plugin

O identificador do plugin é main-design.

/plugin install main-design  # se pedir, rode /reload-plugins
3

Rode o preflight

Antes de qualquer build, confirme que ffmpeg, WebP muxer e playwright-core estão certos.

node scripts/doctor.mjs              # diz exatamente o que falta
node scripts/workspace.mjs --ensure  # cria o workspace e o registro vazio
4

Invoque a skill

Descreva o que quer, ou chame direto.

/main-design:scrollcraft
5

(Opcional) hackear sem instalar

Para editar a skill localmente sem passar pelo marketplace.

claude --plugin-dir ./plugins/main-design

Limitações honestas

O que o projeto assume, de propósito

Direto do README — nada escondido.

Plataforma
Só testado no WindowsOs scripts procuram ffmpeg e Chrome em caminhos de Windows, macOS e Linux, mas nenhum build foi feito num Mac. SCROLLCRAFT_FFMPEG e SCROLLCRAFT_CHROME sobrescrevem a busca.
Custo
Vídeo gerado não é de graçaUm voo de dez pernas em mundo contínuo é gasto real. Uma página construída com assets próprios não custa nada.
Postura
É opinativo de propósitoRecusa layouts e paletas que denunciam página feita por IA, e vai discutir com você sobre o seu pico. Se quiser uma página igual a todas as outras, essa não é a ferramenta certa.
